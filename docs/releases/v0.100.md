# SHY v0.100 — Bounded Intelligence Utilities

Starting from the v0.50 integrated platform, this candidate adds 50 implemented
utility contracts across v0.51–v0.100: retrieval/evidence, workflow planning, data
analysis, security/provenance checks, and operational/release evidence.

The API exposes a catalog, individual evaluation, and bounded batches. The final
evidence pipeline combines scoped ranking, freshness, heuristic injection checks,
redaction, citation-aware context packing, quote validation, and abstention.
All six protected disabled invariants remain disabled. New utilities accept supplied
JSON and do not execute external actions or persist state. Versioned manifests now
exclude capabilities introduced after the requested historical version.

See [the full milestone reference](../intelligence-v100.md) and
[50 runnable examples](../examples/intelligence-v100.json).

Local validation:

- 71 current Python scripts passed, including the actual core startup and API checks.
- All 50 documented utility examples passed through HTTP; targeted arithmetic,
  scope, provenance, cycle, retry, approval-binding, tampering, and failure cases passed.
- 12 web tests passed; lint, type checking, and production build passed.
- Production dependency audit reported zero known vulnerabilities after updating
  Next.js, Vitest, and compatible PostCSS/sharp overrides.
- 21 historical external/provider/version-specific scripts were excluded and listed
  explicitly in the validation report. No real GPU/model-quality benchmark was run.

Database-backed local checks use disposable PGlite. The new GitHub release workflow
adds native PostgreSQL 16 and Python 3.13 coverage, plus web checks and a production
dependency audit. Review CI results on the published candidate commit before rollout.

The development-tool audit still reports high-severity advisories in the
eslint-config-next → fast-glob → micromatch → braces chain. At validation time the
latest braces release is affected and npm suggests a framework-config downgrade;
that downgrade is not applied. This limitation does not appear in the production
dependency audit. Dependency audits are snapshots, not full security certification.

The existing local model, chat UI, database configuration, and Docker deployment
are not automatically replaced. Raw audio/image inference remains disconnected.
