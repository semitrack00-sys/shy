# Research clarification — v0.105.11

SHY can return a deterministic, cited clarification before model generation when two supplied snippets give different values for the same field, or when the existing research workflow flags conflicting evidence. It also asks for usable excerpts when sources contain only links or when a current-information request has no qualifying excerpt. This adds to the existing source-date and citation membership checks.

The field comparison intentionally covers an entire snippet of at most 800 characters in the form `Acme 2026 revenue: 10 USD` or `Acme launch date: 2026-10-12`. Labels are bounded ASCII text, compared after Unicode normalization, whitespace normalization and case folding. Values are bounded decimals with optional %, USD, EUR, HTG, km, mi, kg, lb, days or hours, or valid ISO dates. Numerically equal values such as `10.00 USD` and `+10 USD` agree. Different units, different labels, general prose and invalid/oversized values are not compared. There is no implicit conversion or general semantic inference.

Equal field labels do not prove equal subjects or dates. The reply therefore calls differences **possible disagreements**, displays the supplied values with existing source numbers, and asks which subject/date to use or what evidence resolves the difference. It never chooses a winner or claims independent source truth. Same-publisher pages are not treated as independent authorities. For current requests, only references with qualifying date estimates enter the comparison. At most four pairs are displayed.

Workflow conflict identifiers must map to existing evidence and source numbers; arbitrary conflict reasons are not copied into the response. Malformed references fail safely. These provenance checks do not qualify the existing workflow's heuristic or semantic comparator accuracy.

Research replies carry `research_answer` metadata: mode, model invocation and the fact that semantic truth is unverified. Deterministic `/chat` clarifications are stored as model `research-evidence-checks`, provider `shy-core`, with no stale model-routing claim or model role. They have insufficient-evidence verification status. Ordinary research chat now returns source cards, including available date metadata, using the same checked numbering as its answer. Model-generated research still undergoes date and citation checks.

Validation covers bounded field comparisons, units and date distinctions, matching source numbers, stale-reference exclusion, existing workflow flags, actual `/agent` and project `/chat` HTTP paths, saved history and response metadata against disposable PostgreSQL. Live research credentials, full-page retrieval, general prose comparison, representative model quality and the v0.150 reasoning benchmark remain pending.
